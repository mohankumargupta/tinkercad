## Steps

### Step 1: Plunger cup

<LinkedImage src={plunger1} alt="Plunger" />

Start with sphere 40mm x 40mm x 40mm.

The center of the sphere should be on the workplane (hence the -20.00mm in the diagram)

Turn it into a hole.

<Image src={plunger2} alt="Plunger" />

Now take a duplicate, make it solid, and change it dimensions to be 42mm x 42mm x 42mm

Now select both shapes and center align using align tool.

<LinkedImage src={plunger3} alt="Plunger" />
<LinkedImage src={plunger4} alt="Plunger" />

And now select both and make them a bundle group. A bundle group means they can be moved 
together as one unit, but they are still separate bodies.

<LinkedImage src={plunger5} alt="Plunger" />

Change its color to red and now drag out a torus

<LinkedImage src={plunger6} alt="Plunger" />

Select both shapes and align center

<LinkedImage src={plunger7} alt="Plunger" />

Now drag a box and make it a hole, we are going to use it to chop the model in half vertically.
Make sure it completely covers bottom half the model.

<LinkedImage src={plunger8} alt="Plunger" />

<LinkedImage src={plunger9} alt="Plunger" />
