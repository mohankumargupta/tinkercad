## Steps

## Step 1: Plunger cup



<LinkedImage src={plunger1} alt="Plunger" />

Start with 2 spheres: one solid, one hole

SPHERE 1: 42mm x 42mm x 42mm , solid

SPHERE 2: 40mm x 40mm x 40mm , hole

The center of the spheres should be on the workplane.


<LinkedImage src={plunger2} alt="Plunger" />

<LinkedImage src={plunger3} alt="Plunger" />


Now select both shapes and center align using align tool.

<LinkedImage src={plunger4} alt="Plunger" />

And now select both and an do a union group.

<LinkedImage src={plunger5} alt="Plunger" />


Drag a box and make it a hole, we are going to use it to chop the model in half vertically.
Make sure it completely covers bottom half the model.

<LinkedImage src={plunger6} alt="Plunger" />

<LinkedImage src={plunger7} alt="Plunger" />

Drag a torus onto workplane

<LinkedImage src={plunger8} alt="Plunger" />

Align the torus with the sphere

<LinkedImage src={plunger9} alt="Plunger" />

Union group the lot

<LinkedImage src={plunger10} alt="Plunger" />

<LinkedImage src={plunger11} alt="Plunger" />

Change color to red

<LinkedImage src={plunger12} alt="Plunger" />
