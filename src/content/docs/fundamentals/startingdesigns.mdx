Hardest part is how to start.

## Option 1: Start from scratch

Start with basic shapes when you can. 

Can you identify the base shapes needed? Start from there. 


## Option 2: Start from 2d design

If the design revolves around a complex 2d shape, it might be a better starting point to 
Import a svg file into tinkercad. 

One of the examples on this site is the batman logo, which import a svg.

If you only have png/jpg, then you will need a converter tool, which you can find online.
The tinkercad community seem to like <HyperLink href="https://picsvg.com/">picsvg.com</HyperLink> , but there are others like <HyperLink href='https://image.online-convert.com/convert-to-svg'>online-convert.com</HyperLink>

When picking an image to import, simpler is better.

go to <HyperLink href='https://images.google.com'>images.google.com</HyperLink> and type something
like

```text
cat svg
```

or 

```text
cat svg silhouette
```
