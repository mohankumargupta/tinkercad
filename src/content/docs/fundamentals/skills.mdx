## 🟩 Level 1: Workspace & Navigation

* Account Setup: Create a free personal profile on the Tinkercad Website.
* Camera Controls: Master right-click dragging to orbit, scroll wheel to zoom, and wheel-click to pan.
* ViewCube Navigation: Use the top-left orientation box to quickly snap to standard view angles.
* Home View: Reset a cluttered viewport back to the original default angle.

## 🟨 Level 2: Core Shape Manipulation

* Place Shapes: Drag basic solid shapes from the right panel onto the active blue workplane.
* Resize Objects: Use the white corner handles for dual-axis scaling and black edge handles for single-axis tracking.
* Proportional Scaling: Hold Shift while dragging handles to resize an object without altering its aspect ratio.
* Vertical Positioning: Use the black overhead cone arrow to lift or lower shapes relative to the workplane.
* Rotation: Use the double-ended curved arrows to rotate shapes precisely on three separate axes.

## 🟧 Level 3: Advanced Editing Concepts

* Hole Generation: Convert any standard geometric shape into a negative "Hole" object via the properties panel [0.15].
* Shape Grouping: Select multiple adjacent objects and bind them together into a single combined form using Ctrl + G.
* Material Subtraction: Group a solid shape with a hole shape to permanently cut out geometry.
* Precision Alignment: Select multiple bodies and use the Alignment tool (L) to center or flush edges.
* Smart Duplicate: Use Ctrl + D to duplicate an object along with its movement history to create patterns effortlessly [0.14].

## 🟥 Level 4: Project Finalization

* Scribble Tool: Generate custom 3D geometries based on freehand 2D drawings.
* Sketch Tool: create 2 sketches.
* Revolve Tool: create 2 sketches that have can be revolved to produce 3d object. 
* Measurement Accuracy: Drop a Ruler tool onto the canvas to observe absolute physical distances between components.
* Grid Snapping: Adjust step sizes from 1.0mm down to 0.1mm or turn it off entirely for precise tracking.
* File Exporting: Download finished assemblies as .STL or .OBJ files optimized for 3D printing software slicers.
