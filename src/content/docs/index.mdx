### Grid unit

A critical skill to learn is to change grid units as you work, particularly when you need to move shapes with precision.

The default grid unit is 1.0mm.

When you select a shape and click the right arrow key, it will move the shape 1.0mm to the right.

<Image src={grid} alt="Grid Units" />

### ✏️ Transform

**Move**

If using mouse to move object, first making sure nothing is selected(click off or click blank space), then simply click and drag in one motion.

In tinkercad, it is better to select shape and then use arrow keys to move things around.

| Action | Shortcut | Result |
|--------|----------|--------|
| Horizontal | Arrow Keys | Move 1 grid unit. |
| Horizontal (Large) | `Shift` + Arrows | Move 10 grid units. |
| Vertical off workplane | Drag Up Arrow Cone or press Ctrl+Arrow Keys | Raise or lower object. |

**Rotate**

| Action | Shortcut | Result |
|--------|----------|--------|
| Set Angle | Select Handle → `Tab` → Type # | Rotate to exact degree. |

**Resize**

<LinkButton href="https://www.youtube.com/watch?v=jSN26AqmUR8" variant="primary" target="_blank">Excellent youtube video about scaling objects</LinkButton>

| Action | Shortcut | Result |
|--------|----------|--------|
| Set Dimension | Select Handle → `Tab` → Type # | Resize to exact size. |
| Next Dimension | Press `Tab` | Jump between width/depth/height inputs. |
| Confirm | Press `Enter` | Finalize change. |
